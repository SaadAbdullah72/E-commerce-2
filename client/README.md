# ShopYaro 🛒

A high-converting, production-ready e-commerce platform and admin control panel built with React, Tailwind CSS, and Lucide Icons.

## Features
- **Interactive Storefront**: Live search, flash sales, countdown timers, and special deal classification filters (Lightning Deals, 50% OFF Clearance, Under $5 Store).
- **Admin Control Panel**: Real-time inventory adjustments (+/- stock), low-stock alerts, color variant swatches, bulk batch actions, order fulfillment tracking, and promo coupon generators.
- **Modern Routing & UI**: SEO-friendly dynamic routing, slide-over cart drawer, and isolated full-screen admin operations.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, React Router v6, Lucide React
- **Backend Ready**: Modular component architecture designed for Node.js/Express & MongoDB schemas
